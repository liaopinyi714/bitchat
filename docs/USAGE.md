# 使用说明

## 安装和开始聊天

安装本分支 APK 后设置昵称。中文系统默认使用中文；也可以在关于页面的“应用语言”中切换。无需注册账号。

在主聊天页顶部编辑昵称后，新发送的消息使用新昵称；旧消息保留发送时的名字。改名后的第一条消息重新显示发送者标签，不会并入旧昵称的消息组。改名不更换身份密钥，也不影响自己旧消息的归属、回执或正在发送文件的取消操作；同名用户仍按各自身份区分。

现代 Android 的蓝牙发现需要附近设备权限。仅使用在线频道时，可以跳过本地发现权限；在线连接不需要定位权限。Android 8–11 的蓝牙扫描受系统定位要求限制，详细说明见 [Android 文档](ANDROID.md)。

本地网络聊天使用 BLE，支持的设备还可使用 Wi-Fi Aware。在线聊天需要仓库所有者先完成 [中继部署](DEPLOYMENT.md)。当前手表模块只支持上游本地功能。

## 创建、加入和退出频道

打开频道抽屉，选择创建 / 加入，输入名称。也可发送 `/join #sample`。名称区分大小写，不允许空格或控制字符，最多 255 个 UTF-8 字节；缺少 `#` 时自动补上。

公开频道不需要密码。第一个在该中继成功认证的身份成为频道创建者。名字已经存在时加入原频道，不会创建第二个同名频道。没有全站搜索、固定聊天室、地图或地理频道。自己加入的频道会出现在抽屉中。

加入密码频道时填写共享密码。频道抽屉显示在线、连接中、离线或需要密码。错误密码不会解密出消息。加入已有公开频道时不要填写密码；设置密码应由创建者使用 `/pass`。

选择频道切换聊天目标。频道行的关闭按钮退出该频道并清理本机临时密钥；退出不删除服务器的创建者记录，也不撤销其他人保存的消息。

## 设置和修改密码

创建者连接中继后，在频道中使用 `/pass <password>`。为保持命令解析一致，命令参数中不要包含空格。使用足够长且难以猜测的密码。

客户端在后台派生新密钥，中继确认修改后才切换密钥并提示成功。如果中途断线，会在重连后核对服务器状态。中继未连接时不会把密码修改报告为成功。修改后其他成员需用新密码重新加入，旧密码缓存不能作为新密码下的可读历史。

密码和频道密钥只保留在进程内存中，重启后需要重新输入。创建者身份依赖本机 Noise 密钥；卸载、清除身份或 panic 清除可能失去频道所有权。当前没有账号找回或管理员恢复流程。

## 私聊、历史和媒体

通过用户列表进入私聊，沿用原版 Noise 加密、身份验证、收藏、拉黑和回执。第一次建立会话通常要求双方同时在线。已建立会话的部分小包可在中继短期缓冲；这不是永久离线邮箱或推送服务。

频道近期文本由仍在线、仍保留缓存的客户端同步。所有成员都退出后，不能依靠服务器找回频道历史。图片、文件、语音和实时 PTT 保留原版流程；网络较差时应优先使用文本或语音留言。

消息被中继接收、客户端传输接收、加密送达和已读是不同状态。不要把在线图标或传输确认理解为对方已经阅读。

## 更新和故障

只有相同安装标识和兼容签名的 APK 才能覆盖安装。本分支与原版可以并存，但不能用本分支覆盖原版。调试包的签名可能因构建机器不同而不同；正式发行应按 [签名指南](ANDROID.md#自己的正式签名) 操作。

在线频道持续离线时，先确认部署者能打开 `/health`，再核对域名、HTTPS 和实际网络。健康检查正常仍需双机聊天验证。后台连接受 Android 和厂商电池策略影响，当前没有独立厂商推送。

panic 清除会删除本地身份及聊天数据并关闭连接。操作前确认自己能够接受失去本地历史和频道创建者身份。

完整的加密和中继信任边界见 [安全说明](../SECURITY.md)。
