# 使用前验收与长期维护

本页用于安装后验收和后续维护，覆盖日常聊天、升级与中继运行。自动检查的证据见 [测试记录](TESTING.md)，架构与加密边界见 [功能范围](FEATURES.md) 和 [安全说明](../SECURITY.md)。

## 使用前验收

准备两台 Android 14 或更新系统的手机，使用同一版本 APK、相同中继和合成聊天内容。至少覆盖两个系统版本或不同厂商。Wi-Fi Aware 需要两端硬件支持，不支持的设备应记录为“不适用”，而不是“通过”。

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 安装与升级 | 首次安装；再从已使用的旧分支包覆盖安装 | 冷启动正常，身份指纹、收藏和已保存私聊仍在；没有要求清除数据 |
| 权限 | 拒绝本地发现权限选择在线模式；再授权附近设备 | 在线模式能聊天；授权后能发现附近设备；没有定位请求 |
| 语言与界面 | 中文 / 英文切换，查看主界面、频道、私聊、文件反馈 | 布局沿用原版；系统文案跟随语言；用户名称不被翻译 |
| 公开频道 | 双方加入相同大小写名称，互发文字 | 双向到达，不出现在未加入的频道 |
| 密码频道 | 创建者设置密码；对端用错误 / 正确密码；再次改密码 | 等确认才显示成功，错误密码不能读消息，旧密码失效；重启须重新输入 |
| 昵称与同名 | 改名后再发；两端使用相同昵称 | 新消息新名称，已保存旧消息保留旧名称；未读和回执按身份区分 |
| Noise 私聊 | 双方在线握手，核对身份指纹，再私聊 | 正确对端可读；身份校验、回执、收藏和拉黑可用 |
| 短期离线 | 已有 Noise 会话断网片刻，发送少量私聊后重连 | 在邮箱容量和时限内可恢复；超时或大附件不能假设必达 |
| 网络恢复 | Wi-Fi / 蜂窝切换、断网再恢复、休眠后重连 | 不显示旧连接假在线，恢复后可继续聊天，不重复插入相同消息 |
| 本地 mesh | 关闭互联网，测试 BLE；支持时测试 Wi-Fi Aware | 附近设备仍能交换消息，重新联网不上传他人的本地消息 |
| 蓝牙生命周期 | 连续切换本地传输、撤回再授予附近设备权限 | 不崩溃，不残留假连接，恢复后能重新发现和聊天 |
| 媒体与语音 | 图片、文件、语音留言、取消传输、频道 / 私聊 PTT | 内容可接收，进度和取消正常；目标切换不把语音发到错误会话 |
| 后台 | 锁屏、前后台切换、较长空闲，再收发 | 通知与重连正常；记录厂商限制，不能只测试亮屏状态 |
| 清除 | 在单独测试身份上执行 panic | 本地身份 / 历史和连接被清理，旧回调不能恢复旧数据 |

首次验收后，持续使用至少 24–48 小时，覆盖多次锁屏、断网和重新打开。观察安装数据 / 缓存是否无故持续增加、耗电是否异常、连接能否恢复。短时验收不能证明数周或全部设备的可靠性；长期维护需要持续跟踪真实问题。

记录应用版本、系统大版本、合成复现步骤、预期 / 实际结果与是否通过。原始设备日志、序列号、位置和真实聊天留在本地。项目的物理 Mesh Lab 入口是 `android/tools/release_gate/mesh_lab.py`；按照 Android 仓库规则执行，不上传原始证据。

## 日常使用中的数据

- 昵称不是账号，也不是身份证明。身份依赖本机密钥；更换昵称保留身份，卸载 / 清除数据 / panic 可能失去身份和频道所有权。
- 频道近期历史来自仍在线客户端的内存缓存，不是服务器永久档案。全部成员退出、进程结束或改密码后，历史可能无法同步。
- 频道密码不持久保存，重启后需要重新输入。不要将密码与发行签名密码混淆；二者用途和持有人不同。
- 私聊沿用原版的本地加密持久化。系统复制应用目录或 APK 不等于可恢复的身份备份，Android Keystore 数据不能据此保证迁移。
- 公开频道没有正文端到端加密；需要内容保密时使用强密码频道或验证对方身份后的 Noise 私聊。拒绝旧版媒体明文回退。

## 中继维护

Cloudflare 部署由仓库所有者操作，根目录必须设置为 `worker`。完整步骤及之前 `ERR_PNPM_NO_IMPORTER_MANIFEST_FOUND` 的修复见 [部署说明](DEPLOYMENT.md)。客户端 APK 发布与 Worker 部署互相独立。

每次 Worker 升级前运行 TypeScript、Workerd 测试和 dry-run，确认协议、绑定及存储迁移兼容。0.2.0 没有 Worker 协议或迁移变更；已正确部署此前中继时，不需要为了这次 APK 更新手工迁移数据库。

日常查看 Cloudflare 的请求错误、Durable Objects 用量和免费额度，使用合成双端聊天确认服务。`/health` 仅表示 HTTP 路由可用，不能证明 WebSocket 认证、私聊路由、后台重连和运营商网络都正常。项目没有后台厂商推送服务。

默认不启用业务消息日志。排错优先统计错误类别、数量与耗时，不记录正文、密码、token 或完整连接信息。调整 `MAX_CONNECTIONS` 等参数只能改变应用容量保护，不能扩大平台免费额度。多人语音、文件分片和跨邮箱转发会增加实际用量。

不要删除 Durable Object 命名空间、重命名绑定或删除已应用的迁移标签来“重置”故障；这可能损坏频道所有权和现有数据关系。代码回退也不会自动回退 SQLite 数据。

## 更新与回退

维护者按 [发行指南](RELEASE.md) 保存密钥、递增版本、保留旧资产校验信息和源码 tag。CI 不持有私钥、不自动部署中继、不自动发布 APK。常规依赖更新与功能修复分开提交，优先审查加密、网络、解析和持久化依赖的变更。

用户安装前核对来源、版本、架构和校验值。更新失败先保留现有安装，检查 Android 版本、签名和可用空间。只有受支持的签名迁移才可覆盖旧版本；清除数据不能作为日常排错手段。

Android 通常不允许直接安装较低 versionCode。已发布版本出现问题时，用同一发行密钥发布更高 versionCode 的修复，说明受影响范围。Worker 只在确认旧代码可读取当前数据后回退；协议变化须给出客户端和服务端的配套升级顺序。

## 发布问题报告

普通错误使用仓库 Issue 模板，附上版本和最小合成步骤。安全问题按 [安全报告方式](../SECURITY.md#报告问题) 私密沟通。不要把私钥、聊天、个人身份或完整日志作为公开附件。
