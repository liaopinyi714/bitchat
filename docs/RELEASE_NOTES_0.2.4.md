# bitchat 0.2.4 — 传输、存储与图片处理优化

最低 Android 14（API 34），versionCode 12，沿用长期发行签名，覆盖升级时保留本地数据。

- 修复多频道连接可能交叉等待、单个发送异常中断私聊重试、邮箱重连期间新消息未入队的问题；离开最后一个频道后仍可保留有近期邮箱活动的私聊会话。
- 私聊活动过期后可主动重新握手；停止和重启隔离旧收发任务，恢复后重新公告身份及同步频道，panic 清除私聊目标缓存。
- 收包按发送者顺序处理，增加有界等待和空闲回收，减少积压与无意义协程创建。资源保护触发时的重试及过载边界见优化说明。
- 防止旧历史加载、写入或撤销越过清空 / panic；阻止重复消息 ID 错误合并会话，减少重复写入和全表未读统计。
- 图片改为后台采样处理，修正 EXIF 镜像；固定发送目标并清理取消的临时文件。保存失败不再留下假成功或未完成的系统下载条目。
- Worker 修复异步状态覆盖和失效连接隔离；协议与存储结构兼容，但需要重新部署才能获得服务端修复。
- APK 加入构建来源指纹；发行检查验证源码对应、升级版本和各架构资源一致性，失败产物不会成为正式输出目录。

没有新增账号、位置权限或付费服务。原版 UI 布局、频道与私聊加密格式继续保留。详细范围、资源边界及性能计算见 [整体优化说明](https://github.com/liaopinyi714/bitchat/blob/v0.2.4/docs/OPTIMIZATION.md)，自动检查与待完成的真机验收见 [验证记录](https://github.com/liaopinyi714/bitchat/blob/v0.2.4/docs/TESTING.md)。

两台手机均建议覆盖升级至 0.2.4，然后按 [使用前验收](https://github.com/liaopinyi714/bitchat/blob/v0.2.4/docs/OPERATIONS.md) 复测。维护者从现有 GitHub 项目重新部署 Worker，保持原有绑定和迁移标签，不要删除已有 Durable Object 数据。上传附件与 tag 按 [发行指南](https://github.com/liaopinyi714/bitchat/blob/v0.2.4/docs/RELEASE.md) 操作。
