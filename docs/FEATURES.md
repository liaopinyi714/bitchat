## 需要理解的行为

- 不兼容原版的地理在线频道。自定义频道协议以本仓库为准。
- “公开”表示知道名称的人可以加入。客户端只列出自己加入的频道，不提供公共搜索站点或固定聊天室名单。
- 创建者不是依赖每台手机本地记录决定：同一个中继中，首次成功认证的 Noise 身份成为创建者。离线本地创建与服务器名称冲突时，以服务器记录为准。当前没有中心账号、找回频道所有权或管理员恢复流程。
- 密码加密保护消息内容；频道路由和密码密钥摘要仍可见，不应宣称隐藏存在、强密码学成员认证或群组前向保密。修改密码也无法撤销别人已保存的旧消息。
- 频道同步依靠仍持有近期缓存的在线客户端；没有永久服务器频道历史。密码改变后，旧密钥的缓存不能作为新密码的可读历史。
- 离线邮箱不缓存公告、握手或 PTT，原版分片媒体也不在服务器离线缓冲中。没有已建立的 Noise 会话时，需要双方在线完成握手。服务器写入或 socket 接收确认不等于 UI 已读 / 已送达。
- 在线中继不会把远端收到的包自动转发到附近 BLE，也不会把本地陌生人的消息上传到互联网。只有本机主动发布到所选频道的包会同时发送到本地和在线传输。
- 图片和文件沿用原版分片与大小约束；默认不依赖 R2 存储大附件。
- 不保留频道密码明文或持久群组密钥；应用重启后重新输入密码。私聊历史使用原版的本地加密持久化。
