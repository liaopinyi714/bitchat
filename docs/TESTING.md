# 验证记录

当前记录对应 0.2.2 权限页导航栏修复版本。以下结果来自本地构建和合成测试数据，不代表已经完成真实手机、运营商网络或正式 Cloudflare 账号上的验收。

0.2.2 仅修改手机权限页的边距与系统导航栏外观。重新检查手机 / Wear debug 构建、手机 R8 release、JVM 回归、Lint 和客户端契约；沿用 0.2.1 的 Worker 测试与部署预演记录，因为中继代码未改动。静态检查不能证明实际设备的绘制效果：权限说明页还需在手势 / 三键导航、深色 / 浅色主题、大字体和横屏下核对底部连续背景、按钮避让及正文滚动。不要通过清除日常安装数据来重新触发引导；使用独立测试安装或设备进行首次启动检查。

0.2.1 新增 17 项手机回归（包括 Android 14 / 15 上的后台启动边界），其中 9 项共享蓝牙与文件解析回归同步到 Wear。覆盖：订阅确认与失败、45 秒无回调超时、立即拒绝服务发现、服务端回应时权限撤销、重复订阅 / 取消订阅、清理任务生命周期、5 万个内容块和溢出长度，以及后台启动拒绝和无关广播。蓝牙测试使用明确的合成电源配置和虚拟时间，避免测试 scope 提前取消使超时用例失真。另恢复此前跳过的三个命令测试，检查大小写加入命令的实际频道状态、未知命令反馈与测试结束清理；当前没有跳过用例。

## Lint 与语言覆盖

0.2.1 删除 `android/app/lint-baseline.xml`，手机与 Wear 均设置 `abortOnError=true`、`checkReleaseBuilds=true`。权限、数量、格式、代码正确性等错误会使 CI 失败；发布构建还运行 release vital 检查。

此前手机的 47 项非翻译错误（25 项权限、19 项数量资源和 3 项缩进）已逐项处理；Wear 共享代码的 27 项错误一并消除。GATT 客户端仅对被 `runIfCurrent` 包裹的回调局部标注权限误报：该包装在运行时捕获 `SecurityException` 并释放连接，并有权限撤销回归。没有将运行错误加入新基线或全局关闭权限检查。

`MissingTranslation` 明确改为警告：保留的社区语言包缺少部分原有或新增文案，继续使用 Android 的英文回退。**这 406 项是检查严重性调整，不是完成了 406 项翻译。** 中文、简体中文、繁体中文每个默认字符串的覆盖与格式参数仍由强制契约测试检查；实际中文命令、频道、权限和语言切换另有行为回归。没有删除其他语言包，也没有把英文复制成假翻译。

0.2.1 的最终报告数量见本页检查表。剩余警告包括社区翻译完整性、未使用资源、旧系统条件、KTX 建议、排版和依赖更新提示。它们没有被隐去；不能将“错误为零”解释为“全部警告消失”或完成了独立安全审计。完整构建报告仅保留在本地，不上传原始环境日志。

历史对比：0.2.0 为手机 453 errors / 418 warnings、Wear 27 errors / 50 warnings；0.1.6 为手机 468 errors / 418 warnings、Wear 37 errors / 51 warnings。当时 `abortOnError=false`，Gradle 成功并不表示 Lint 合格。
